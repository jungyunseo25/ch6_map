# 🚌 부산 지하철 역별 이용객 수 지도 분석 앱

부산 지하철 1~4호선 역별 위치 및 이용객 수 데이터를 지도에 visualizing(시각화)해주는 **Streamlit 웹 애플리케이션**입니다.

---

## 📌 주요 기능
1. **CSV 데이터 업로드**: `busan_subway.csv` 파일 업로드 시 데이터프레임 자동 표출
2. **호선별 데이터 필터링**: `st.multiselect`를 통해 원하는 호선만 선택하여 확인 가능
3. **이용객 상위 5개 역 표출**: 선택된 호선 데이터 내 이용객 수 상위 5개 역 자동 계산 및 표시
4. **Folium Interactive 지도 시각화**:
   - 이용객 수에 비례한 **원 크기(면적 비례 제곱근 적용)** 표시
   - 호선별 고유 색상 구분 (1호선: 주황, 2호선: 초록, 3호선: 갈색, 4호선: 파랑)
   - **Tooltip**: 마우스 호버 시 호선 및 역명 표시
   - **Popup**: 마우스 클릭 시 상세 이용객 수(명) 표시

---

## 📂 데이터 형식 (`busan_subway.csv`)
업로드하는 CSV 파일은 다음과 같은 열(Column) 구조를 가져야 합니다:

| 호선 | 역명 | 위도 | 경도 | 이용객수 |
| :--- | :--- | :--- | :--- | :--- |
| 1호선 | 서면 | 35.1577 | 129.0591 | 85000 |
| 2호선 | 해운대 | 35.1631 | 129.1636 | 42000 |
